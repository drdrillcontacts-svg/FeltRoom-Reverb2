# FELTROOM Reverb — تحديث ظاهر ناب‌ها

این نسخه ظاهر ناب‌ها را به استایل مرجع نزدیک می‌کند: بدنه مشکی فلزی، حلقه نورانی گرادیانی صورتی/بنفش، نشانگر روشن و عمق بیشتر. ساختار کلی رابط کاربری، پارامترها و منطق پردازش صدا تغییر نکرده‌اند.

## روش استفاده در GitHub

1. فایل ZIP را استخراج کنید.
2. در مخزن `FeltRoom-Reverb` فایل `Source/PluginEditor.cpp` را باز کنید.
3. Edit (مداد) را بزنید و کل محتوا را با فایل `Source/PluginEditor.cpp` همین بسته جایگزین کنید؛ یا همه فایل‌های این بسته را برای همسان‌سازی سورس آپلود کنید.
4. Commit changes را بزنید و از Actions دوباره Build را اجرا کنید.

این تغییر فقط ظاهر ناب‌ها را عوض می‌کند و عمداً به DSP یا پارامترهای پلاگین دست نمی‌زند. پس از کامپایل، نتیجه را در Studio One بررسی کنید.
